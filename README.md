# FileStorage

FileStorage is a small public repository used to host two ZIP downloads linked from [ZEROfilez](https://github.com/falker47/ZEROfilez).

It is not a standalone application or a software development project. The repository contains only downloadable archives, with no source code, build process or installation scripts of its own.

## Available archives

| Archive | ZEROfilez catalog entry | Size |
|---|---|---:|
| [SkyEditor.SaveEditor.zip](SkyEditor.SaveEditor.zip) | PMD Save Editor | 2,180,416 bytes |
| [GBA_HackROM_Toolz[ZEROfilezRepack].zip](GBA_HackROM_Toolz%5BZEROfilezRepack%5D.zip) | HackROM Tools Pack | 63,469,257 bytes |

Both files are referenced by the ZEROfilez download catalog in [`js/data.js`](https://github.com/falker47/ZEROfilez/blob/main/js/data.js).

## Downloading and using the archives

The archives can be downloaded directly here or through ZEROfilez.

Extract and inspect the files locally before use. Consult the original software providers for compatibility, dependencies and operating instructions. This repository does not establish those requirements for the packaged archives.

Keep independent backups before experimenting with game save files or other data.
